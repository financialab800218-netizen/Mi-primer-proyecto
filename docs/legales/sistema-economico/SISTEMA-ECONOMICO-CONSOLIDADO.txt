SECCION 3 - CATEGORIAS DE PROFESOR TCP
================================================================

Categoria   - % TCP - % Plataforma - Bono base    - Requisito
Bronce      - 30%   - 70%          - 490 CUP      - 5-10 estudiantes
Plata       - 40%   - 60%          - 2,290 CUP    - 20-30 estudiantes

Reglas:
- El % crece con la categoria. Nunca decrece.
- Bono base garantizado cada mes.

Distribucion del % plataforma:
- 50% operativo (VPS, IA, soporte)
- 30% fondo de crecimiento
- 20% reserva


================================================================
SECCION 4 - FORMULA B1+B2+B3+B4
================================================================

Compensacion TCP mensual =
    B1 (estudiantes x factor x % categoria)
  + B2 (contenido x calidad + reutilizacion x % categoria)
  + B3 (mejoras + dominios + retenciones)
  + B4 (validaciones x valor)

Con minimo garantizado por categoria.


B1 - BONO POR ESTUDIANTES
B1 = Estudiantes x Factor nivel x Factor uso x % categoria

Factores por nivel:
Primaria          - 15 CUP
Secundaria        - 25 CUP
Preuniversitario  - 40 CUP
Universidad       - 55 CUP


B2 - BONO POR CONTENIDO
B2 = (Contenido x Calidad) + (Reutilizacion x % categoria)

Calidad:
Basica      - 40 CUP
Buena       - 60 CUP
Excelente   - 85 CUP

Reutilizacion:
1-5 veces     - 10 CUP
6-15 veces    - 15 CUP
16+ veces     - 20 CUP


B3 - BONO POR MEJORAS Y DOMINIO
B3 = (Mejoras x 50) + (Dominios x 30) + (Retenciones x 20)


B4 - BONO POR VALIDACION IA
B4 = Validaciones x valor

Escala:
Basica    - 50 CUP
Media     - 100 CUP
Experta   - 150 CUP

================================================================

Monto:              Libre eleccion del TCP segun necesidad y disponibilidad

Ventana solicitud:  Dias 1-5 de cada mes
Procesamiento:      Dias 6-10 del mes

SECCION 8 - SISTEMA DE REEMBOLSOS
================================================================

Curso no iniciado:                100% reembolso
Curso iniciado <30%:              50% reembolso
Curso iniciado >30%:              No reembolsable
Curso falla por culpa del TCP:    100% reembolso
Curso falla por culpa del alumno: No reembolsable

ATENCION - Limitaciones cuando ya se pago al TCP:

1. Si el TCP acepta devolucion voluntaria:
   Se ejecuta reembolso normal.

2. Si el TCP no acepta:
   Se retiene del proximo ingreso del TCP.

3. Si no hay ingresos futuros:
   La plataforma absorbe el costo y marca incidente.

4. Poliza detallada en contrato de licencia TCP.

================================================================

Base legal: Cumplimiento Ley 176, Decreto 160/2026, Decreto-Ley 114

REGLA DE ORO:
"Un agente N0 no puede hacer nada sin supervision."

NIVELES:
N0 - Pre-aprendiz   - Solo observar y aprender
N1 - Aprendiz       - Responder en chat interno con supervision
N2 - Auxiliar       - Redactar borradores para revision
N3 - Profesional    - Responder a clientes con auditoria
N4 - Senior         - Actuar en rutinas con revision periodica
N5 - Doctor         - Autonomia plena con auditoria

REQUISITOS POR SALTO:
1. Formacion completa
2. Examen teorico
3. Examen practico
4. Aval del asesor humano
5. Analisis de factibilidad
6. Analisis de impacto

Almacenamiento publico      ->  Repositorio publico
Sistema de archivos         ->  Gestor de datos

SECCION 15 - FLUJOS FINANCIEROS
================================================================

FLUJO 1 - ALUMNO RECARGA:
Alumno -> PWA -> Recargar -> Metodo -> Pago -> Confirmacion -> Saldo acreditado

FLUJO 2 - ALUMNO COMPRA CURSO:
Alumno -> Catalogo -> Inscribirse -> Descuento de billetera ->
Reparto (TCP% + Plataforma%) -> Registro en movimientos

FLUJO 3 - TCP COBRA:
Acumulacion diaria -> Cierre mensual (dia 5) ->
Calculo B1+B2+B3+B4 -> Bono base garantizado ->
Disponible desde dia 6

FLUJO 4 - TCP RETIRA:
Solicitud (dia 1-5) -> Validacion -> Procesamiento (dia 6-10) ->
Transferencia a tarjeta/USDT -> Confirmacion
