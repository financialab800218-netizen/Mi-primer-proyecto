
# Principio de Responsabilidad Legal del Sistema

**Versión:** 1.0
**Fecha:** 2/octubre/2026
**Autor:** Yosbel Collazo Avila + Socio IA
**Estado:** Oficial — Principio rector del sistema
**Cumplimiento:** Ley 176 | Decreto 160/2026 | Ley 149/2022 | Decreto-Ley 370

---

## 1. Objetivo

Establecer las reglas de responsabilidad legal del sistema multi-agente del Ecosistema Mayabeque, definiendo la doble estructura (interna/externa) y los principios no negociables de operación.

---

## 2. Principio Fundamental

Para adentro, sistema colaborativo con IA. Para afuera, Yosbel como único responsable legal.

---

## 3. La Doble Estructura

### 3.1. Capa INTERNA (Nuestro Sistema)

| Aspecto | Detalle |
|---------|---------|
| Que es | El ecosistema de agentes IA, base de conocimiento, retroalimentacion |
| Visibilidad | Solo interna |
| Funcion | Todos los agentes se nutren, se actualizan, se retroalimentan |
| Beneficio | Informacion actualizada para clientes, decisiones anticipadas |
| Responsable | Yosbel |

### 3.2. Capa EXTERNA (Frente a la Sociedad)

| Aspecto | Detalle |
|---------|---------|
| Que es | La cara visible: PDL DESSPEZ, Ecosistema Mayabeque |
| Visibilidad | Publica |
| Funcion | Operar legalmente, cumplir, crecer |
| Beneficio | Crecimiento sostenible y legitimo |
| Responsable | Yosbel, unico responsable legal |

## 6. Checklist de Legalidad

Antes de cualquier accion publica:

| # | Pregunta | Respuesta esperada |
|---|----------|-------------------|
| 1 | Esta Yosbel como responsable? | Si |
| 2 | Se respalda en una norma? | Identificada |
| 3 | Es trazable a la operacion real? | Si |
| 4 | Hay riesgo de comprometer a terceros? | No |
| 5 | Respeta el Decreto 160/2026? | Si |
| 6 | Cumple la Ley de Proteccion de Datos? | Si |
| 7 | Se documenta en GitHub? | Si |

**Si alguna respuesta es NO, no se ejecuta.**

---

## 7. Los 5 Blindajes Legales

1. **Un solo responsable legal:** Yosbel firma todo
2. **Trazabilidad a la norma:** Documentado en GitHub
3. **Separacion interno/externo:** No se mezclan
4. **Consentimiento y datos:** Ley 149/2022 aplicada
5. **Cumplimiento tributario:** ONAT informada

---

## 8. Las 10 Reglas Operativas Permanentes

| # | Regla |
|---|-------|
| 1 | Toda accion publica lleva la firma de Yosbel |
| 2 | Toda accion interna es para alimentar el sistema |
| 3 | Toda accion tiene base legal trazable |

| 5 | Todo dato personal se maneja con Ley 149/2022 |
| 6 | Toda operacion economica se declara |
| 7 | Todo se documenta en GitHub |

## 9. Ejemplos Practicos

### Ejemplo 1. Publicar en Facebook

**Flujo correcto:**
1. Sistema interno analiza informacion
2. Yo te sugiero contenido
3. Tu decides publicar
4. Tu publicas (con tu nombre)
5. Tu asumes responsabilidad

### Ejemplo 2. Responder a un cliente

**Flujo correcto:**
1. Cliente escribe a tu WhatsApp
2. Tu consultas al sistema
3. Yo te doy informacion actualizada
4. Tu redactas respuesta (firmada por ti)
5. Tu envias

### Ejemplo 3. Detectar oportunidad

**Flujo correcto:**
1. Sistema detecta oportunidad en redes
2. Yo te alerto
3. Tu decides si actuar
4. Tu ejecutas (con tu responsabilidad)
