PARTE XII: COMO OPTIMIZAR COSTOS

1. Usar Groq en lugar de OpenAI para Whisper (gratis)
2. Usar Gemini en lugar de GPT-4 Vision (gratis)
3. Usar Oracle Cloud Free en lugar de Hetzner (gratis)
4. Cache de respuestas frecuentes (reduce DeepSeek)
5. Batch de operaciones (reduce llamadas API)
6. Modelo DeepSeek chat (mas barato que reasoner)
7. Reservas y limites mensuales en DeepSeek

Ahorro potencial: 50 por ciento del costo mensual.
