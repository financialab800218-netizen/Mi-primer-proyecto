## 1. Resumen Ejecutivo

El Ecosistema Mayabeque busca un socio inversionista para reactivar y escalar un complejo productivo agroindustrial en Bejucal, Mayabeque, Cuba. Con inversiones de 20 a 50 mil USD se puede transformar una operacion de 590 USD/mes en una de 2000 a 5000 USD/mes, con retorno estimado en 12 a 24 meses.
