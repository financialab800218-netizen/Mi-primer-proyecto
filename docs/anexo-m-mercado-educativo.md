PARTE I: CONCLUSIONES CLAVE

1. Plataformas universitarias cerradas limitan a profesores.
2. Demanda multinivel no cubierta por el sistema formal.
3. Usuarios buscan cosas prácticas para Cuba hoy.
4. NO planes estándar. Flexibilidad curricular.
5. Cuatro motores de aprendizaje:
   - Necesidad práctica (aprende el que necesita hacer algo)
   - Obligación formal (o el que por obligación tiene que hacerlo)
   - Reconversión laboral
   - Proyección externa
